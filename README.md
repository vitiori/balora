# Balora

Web de [Balora](https://vitiori.github.io/balora/), app de finanzas personales para Android: política de privacidad y
condiciones de uso en inglés, español y francés. La publica GitHub Pages con Jekyll.

| Página | Inglés | Español | Francés |
|---|---|---|---|
| Portada | `/` | `/es/` | `/fr/` |
| Privacidad | `/privacy/` | `/es/privacidad/` | `/fr/confidentialite/` |
| Condiciones | `/terms/` | `/es/condiciones/` | `/fr/conditions/` |

El nombre del responsable, el correo y la fecha de la última actualización están en `_config.yml`. Al cambiar un texto,
se cambia en los tres idiomas y se actualiza la fecha.
